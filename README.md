# Научный журнал «Экономика и общество»

Официальный сайт рецензируемого научного журнала для публикации, управления и онлайн-приёма материалов.

🔗 **Официальный сайт:** https://economikaobshestvo.ru

##  О проекте

Сайт разработан для автоматизации работы научного издания. Веб-ресурс позволяет публиковать новые выпуски, предоставляет удобный архив материалов для читателей и систему онлайн-подачи рукописей для авторов.

### Основные возможности

* **Публичный веб-интерфейс:**
  * Отображение свежего выпуска журнала на главной странице.
  * Архив всех выпусков с поиском и фильтрацией по годам и номерам.
  * Динамический раздел «О нас» с информацией о редакции, издателе, ISSN и периодичности.
  * Форма подачи статей авторами с загрузкой рукописей и автоматической отправкой материалов на e-mail редакции.
  * Раздел политики конфиденциальности.

* **Панель администратора:**
  * Добавление, редактирование и удаление выпусков (обложки и PDF-документы).
  * Управление текстовым контентом страниц сайта.
  * Защищенная авторизация с ограничением попыток входа.


##  Стек технологий

* **Backend:** PHP 7.2+ (Native Sessions, PDO, Fileinfo API, Native Mail API)
* **Database:** MySQL / MariaDB (utf8mb4)
* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid, CSS Variables), ES6 JavaScript
* **Server:** Apache (`.htaccess` для маршрутизации и безопасности)


##  Безопасность и Архитектура

При разработке сайта особое внимание уделено защите данных и отказоустойчивости (OWASP):

1. **Защита от SQL-инъекций:** Все запросы к базе данных выполняются через PDO с использованием подготовленных выражений (Prepared Statements).
2. **CSRF-защита:** Все формы сайта защищены одноразовыми токенами с криптографически стойкой валидацией.
3. **Безопасная загрузка файлов:**
   * Валидация загружаемых обложек и PDF-файлов по реальным сигнатурам и MIME-типам (а не по расширению файла).
   * Генерация уникальных безопасных имён файлов при сохранении на сервер.
   * Запрет исполнения скриптов на уровне серверных конфигураций в директориях загрузки (`.htaccess`).
4. **Защита авторизации:**
   * Ограничение количества попыток входа по IP-адресу (Rate-Limiting) для защиты от подбора паролей.
   * Регенерация идентификаторов сессий после аутентификации.
5. **SEO & Конфиденциальность:**
   * Служебные разделы и обработчики скрыты от индексации поисковыми системами (`robots.txt`).
   * Защита от E-mail Header Injection при отправке писем.


## Структура базы данных

База данных включает в себя следующие основные таблицы:

* `issues` — хранение сведений о выпусках журнала (заголовок, описание, пути к обложке и PDF).
* `site_content` — хранение динамического текстового наполнения страниц.
* `login_attempts` — учет попыток входа в систему для защиты от подбора паролей.
